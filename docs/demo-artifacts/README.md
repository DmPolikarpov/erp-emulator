# Скриншоты и видео показа

Каталог для артефактов ручного чек-листа ([`../demo-checklist.md`](../demo-checklist.md)).
В git кладём только статичные PNG — их немного и они нужны для README/приёмки:

| Файл | Что на нём |
| --- | --- |
| `01-cabinet-roles.png` | экран входа с ролями контура |
| `02-dairy-schema.png` | демо-схема завода на холсте |
| `03-metrics-panel.png` | панель «Показатели процесса» с подписью `с сервера` |
| `04-client-order.png` | карточка заказа клиента с активным шагом |

Правила:

- разрешение — как на экране показа (не обрезать подпись источника в панели);
- на скриншоте метрик должны быть видны плитки «Ожидание шага», `SLA` и «Брак»;
- **видео в репозиторий не коммитим** — оно растёт в истории git; кладём ссылку
  в журнал прогона чек-листа (или во внешнее хранилище команды);
- скриншоты перезаписываются при изменении интерфейса, а не копятся по датам.
